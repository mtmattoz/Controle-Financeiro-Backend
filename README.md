# Controle Financeiro

Sistema de controle financeiro desenvolvido com Java, Spring Boot e PostgreSQL.

## Tecnologias

- Java
- Spring Boot
- Spring Data JPA
- PostgreSQL
- Maven
- Lombok

## Funcionalidades

- Cadastro e login de usuários
- Cadastro de receitas
- Cadastro de categorias
- Cadastro de transações
- Filtro por categoria e tipo
- Cálculo de entradas, saídas e saldo
- Relatórios por mês
- Gastos agrupados por categoria

## Estrutura

O projeto utiliza uma arquitetura em camadas:

- Model
- Repository
- Service
- Controller

## Status

Backend funcional em desenvolvimento. O próximo passo é implementar melhorias de segurança e realizar a integração de um agente financeiro de IA.
